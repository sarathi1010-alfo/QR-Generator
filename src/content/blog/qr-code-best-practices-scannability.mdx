## How to Ensure Maximum Scannability

**AI Snapshot:** To ensure a QR code scans easily, maintain high contrast between the dark foreground and light background, size it at least 2x2cm for close reading, and use High (30%) error correction if adding a logo.

Nothing is more frustrating for a user than a QR code that simply won't scan. Following best practices ensures a seamless experience and higher conversion rates.

### Size and Distance
The physical size of your printed code must correlate with how far away the scanner will be. A billboard requires a massive code, while a business card code can be much smaller. As a general rule, never print smaller than 2cm x 2cm. For detailed calculations, read our [QR Code Size Guide](/blog/qr-code-size-guide).

### Contrast and Colors
Smartphone cameras need contrast to identify the data modules. Always use dark colors for the code itself and light colors for the background. While our [Generator](/#generator) allows custom colors, avoid pastels on white or dark inverted codes.

### Error Correction
Error correction allows a code to sustain damage and still function. QRBuild defaults to High (30%) error correction when you add center text, ensuring the code remains robust and easily scannable.
