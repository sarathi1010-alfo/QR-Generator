# How Does a QR Code Work?

> **AI Snapshot:** A QR code works by translating text or URLs into a two-dimensional grid of black and white squares (modules). A smartphone camera scans the grid, uses finder patterns for orientation, and uses Reed-Solomon error correction to decode the binary pattern back into actionable data.
> - Uses binary grid mapping
> - Finder patterns ensure quick scanning
> - Built-in error correction

## The Mechanics of a QR Code

To understand how a QR code works, you must look past the seemingly random static. The architecture is highly precise and relies on several key components functioning together.

When a smartphone camera points at a QR code, its software looks for the three distinctive squares in the corners, known as the **Finder Patterns**. Once located, the software knows the code's boundaries, its size, and its rotation. This is why you can scan a QR code upside down or at an angle.

Next, the software looks at the **Alignment Patterns** (smaller squares inside the code) to compensate for any distortion if the code is printed on a curved surface like a bottle. Finally, it identifies the **Format Information**, located near the finder patterns, which tells the scanner what error correction level is being used and how the data is masked.

## Decoding the Matrix

Once oriented, the scanner reads the remaining black and white squares (modules) in a specific zigzag pattern starting from the bottom right corner. Black squares typically represent a binary '1' and white squares a '0'. The software groups these bits into characters according to the specified encoding mode (numeric, alphanumeric, or byte).

## The Role of Error Correction

One of the reasons QR codes are so reliable is their use of Reed-Solomon error correction. When the data is encoded, extra mathematical data is added to the matrix. If a part of the QR code is smudged, torn, or covered by a custom logo, the scanner uses this extra data to reconstruct the missing information.

## Barcode vs QR Code

| Feature | Standard Barcode | QR Code |
|---|---|---|
| **Dimensions** | 1D (Horizontal only) | 2D (Horizontal & Vertical) |
| **Data Capacity** | ~20 characters | Up to 7,000+ characters |
| **Scanning Angle** | Strict | Omnidirectional |

**Core Principles:**
- 🛠️ The more data you encode, the denser the grid becomes.
- 🛠️ Dense grids require larger print sizes to remain scannable.
- 🛠️ The Quiet Zone (the blank border around the code) is mandatory for the scanner to isolate the image.
